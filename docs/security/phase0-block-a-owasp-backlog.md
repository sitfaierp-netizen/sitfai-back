## Decision

These findings are not suppressed or ignored. They are deferred from Block A because the required remediation is a coordinated Spring Boot/Spring Framework/Spring Security/Tomcat/Jackson dependency-train upgrade, materially broader than tenant isolation. The immediate next security maintenance item must:

1. map every CRITICAL/HIGH CVE to the exact applicable code path and configuration;
2. discard only demonstrated false-positive CPE matches with documented evidence;
3. choose a currently supported Spring Boot BOM containing fixed framework, security, Tomcat, and Jackson versions;
4. upgrade Connector/J independently if needed;
5. rerun all 383+ tests, signed-JWT tenant E2E, Flyway, JaCoCo, and Dependency-Check;
6. tighten the Dependency-Check failure policy after the initial evidence-backed triage.
